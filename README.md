# Arsh Party

Сайт вселенной Arsh Party: пять направлений для праздника, у каждого своя звезда.

| Звезда | Направление | Адрес |
|---|---|---|
| Оранжевая | Доставка блюд с мангала | `/mangal` |
| Красная | Скорая шашлычная помощь (СШП) | `/sshp` |
| Зелёная | Событийный кейтеринг | `/catering` |
| Розовая | Организация мероприятий | `/events` |
| Чёрная | Ведущий на мероприятие | `/host` |

Полное техническое задание и текущий статус лежат в `ТЗ.md`.

## Запуск на Mac

**1. Установите Node.js** (один раз). Нужна версия 18.18 или новее, лучше 20 или 22 LTS.
Скачайте установщик с [nodejs.org](https://nodejs.org) и проверьте в Терминале:

```bash
node -v
```

**2. Откройте папку проекта в Терминале:**

```bash
cd ~/Documents/CLAUDE_WORKSPACE/"arsh party site"/arsh-party
```

**3. Установите зависимости** (один раз и после каждого изменения `package.json`):

```bash
npm install
```

**4. Запустите сайт в режиме разработки:**

```bash
npm run dev
```

Откройте в браузере http://localhost:3000. Правки в коде появляются сразу, без перезапуска.

**Посмотреть с телефона:** телефон и Mac должны быть в одной Wi-Fi сети. Запустите `npm run dev -- -H 0.0.0.0`, узнайте IP Mac (Системные настройки → Wi-Fi → Подробнее) и откройте на телефоне `http://<IP>:3000`.

### Другие команды

| Команда | Что делает |
|---|---|
| `npm run build` | Боевая сборка, заодно проверяет типы |
| `npm run start` | Запуск собранной версии |

## Архитектура

```
src/
├─ app/
│  ├─ layout.tsx        шрифты, мета, контент из базы для всех страниц
│  ├─ globals.css       дизайн-токены, светлая и тёмная темы
│  ├─ (site)/           публичный сайт: шапка с разделами, подвал, главная
│  ├─ admin/            админка: вход, контакты и тексты, направления, меню
│  └─ not-found.tsx
├─ components/
│  ├─ brand/       ArshLogo — главный логотип, звезда меняет цвет
│  ├─ ui/          Star, Plate, Ribbon, ButtonLink, иконки
│  ├─ admin/       формы админки
│  ├─ content/     ContentProvider — контент для клиентских компонентов
│  ├─ layout/      Header + SectionNav, Footer, FloatingContacts, EdgeSparks
│  ├─ home/        HeroConstellation, FireParticles, DirectionCard,
│  │               AboutArsh, Reviews, HowItWorks, SocialFeed, Contacts
│  └─ order/       OrderSection, LeadForm — заявка на мероприятие
├─ content/
│  ├─ directions.ts  пять звёзд: названия, теги, логотипы, механика
│  ├─ reviews.ts     отзывы и рейтинги площадок
│  └─ site.ts        телефоны, мессенджеры, адрес, часы
├─ app/api/lead/   приём заявки → Supabase + Telegram
└─ lib/
   ├─ fire-particles.ts  искры в hero и по краям экрана
   ├─ lead.ts            поля и проверка заявки (браузер и сервер)
   ├─ telegram.ts        уведомления в Telegram
   ├─ supabase.ts        база и хранилище фото через REST
   ├─ content.ts         контент = значения по умолчанию + правки из админки
   ├─ admin-session.ts   вход в админку по паролю
   ├─ menu.ts            меню: категории, цены, проверка
   └─ social.ts          свежие посты VK, Instagram, Telegram
supabase/schema.sql  таблицы заказов и заявок
public/brand/        логотипы (SVG и исходники), directions/ — логотипы направлений
public/photos/       фото Арша для блока «О проекте» и карточки ведущего
```

**Принципы:**
- **Данные отдельно от вёрстки.** Все пять направлений описаны в `content/directions.ts`. Страницы и карточки собираются из этих данных: новая звезда — новая запись.
- **Один акцент.** Цвет каждой звезды задаётся CSS-переменной `--accent`. Компонент, окрашенный в цвет звезды, получает её через `accentVars()`. Отсюда плавное перетекание цвета при выборе звезды.
- **Стили на CSS Modules.** Глобальные токены в `globals.css`, у каждого компонента свой `.module.css`. Никаких лишних библиотек.
- **Серверные компоненты по умолчанию.** На клиенте работает только то, что требует интерактива (`HeroConstellation`).
- **Ключи только на сервере.** Telegram и Supabase будут вызываться из API-роутов, браузер к ним напрямую не ходит.

## Админка

Адрес: `/admin` (локально http://localhost:3000/admin). Вход по паролю из `ADMIN_PASSWORD`.

| Раздел | Что меняется |
|---|---|
| Контакты и тексты | Подзаголовок на главной, телефоны, ссылки WhatsApp и Telegram, соцсети, Telegram-канал, адрес, часы, регион, описание для поисковиков |
| Направления | Название, короткое имя, строка пользы, теги и текст кнопки у каждой из пяти звёзд |
| Меню и цены | Блюда доставки: название, категория, цена, вес, описание, фото, наличие, порядок |

Сохранение сразу видно на сайте. Для работы админки нужен Supabase (ключи ниже) и выполненный `supabase/schema.sql` — он создаёт таблицы `content`, `menu_items` и хранилище фото `media`.

Цвета, логотипы, отзывы и фото Арша пока меняются в коде.

### Кухня: `/kitchen`

Экран «Сегодня на огне» для повара, удобен с телефона. Одно нажатие на блюдо — оно появляется на сайте или скрывается. Кнопка «Скрыть всё — конец дня» и «Добавить блюдо дня» (название, раздел, цена, вес; фото и описание потом в админке).
Вход по отдельному паролю `KITCHEN_PASSWORD`: повар не видит остальную админку. Владелец из админки попадает на кухню без пароля (вкладка «Кухня»).

## Как менять контент в коде

**Контакты.** Поля в `src/content/site.ts`. Пустые поля (`null`) на сайте не показываются. Чтобы появились Instagram и ВКонтакте, впишите полные ссылки в `instagramUrl` и `vkUrl`.

**Отзывы.** `src/content/reviews.ts`. Новый отзыв — новая запись в `reviews`, новая площадка — запись в `reviewPlatforms`. Рейтинги площадок обновляйте вручную.

**Тексты направлений.** Правьте `src/content/directions.ts`: `title`, `tagline`, `cta`.

**Цвета.** Переменные `--c-orange`, `--c-red` и другие в `src/app/globals.css`. Для каждого цвета есть пара `--on-*`: цвет текста поверх него.

## Ключи и сервисы

Все ключи — в файле `.env.local` (образец: `.env.example`). Без ключа функция просто выключается, сайт не ломается.

| Что | Переменные | Без них |
|---|---|---|
| Заявки в Telegram | `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` | Если нет и Supabase — форма просит позвонить |
| Заявки в базу | `SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY` | Если нет и Telegram — форма просит позвонить |
| Посты ВКонтакте | `VK_SERVICE_TOKEN` | Карточка профиля вместо постов |
| Посты Instagram | `INSTAGRAM_ACCESS_TOKEN` | Карточка профиля вместо постов |
| Посты Telegram-канала | поле в админке или `telegramChannel` в `src/content/site.ts` | Колонки Telegram нет |
| Админка | `ADMIN_PASSWORD` (и по желанию `ADMIN_SESSION_SECRET`) | Вход в админку закрыт |
| Кухня | `KITCHEN_PASSWORD` | Повар войти не может; владелец заходит через админку |

**Telegram-бот.** Напишите @BotFather → `/newbot` → получите токен. Напишите своему боту любое сообщение, откройте `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и возьмите `chat.id`.

**Токен Instagram** действует 60 дней. Продление: откройте `https://graph.instagram.com/refresh_access_token?grant_type=ig_refresh_token&access_token=<ТОКЕН>` и замените значение в `.env.local` и на Vercel.

После изменения `.env.local` перезапустите `npm run dev`.

## База данных

1. Создайте проект на [supabase.com](https://supabase.com).
2. Откройте SQL Editor, вставьте содержимое `supabase/schema.sql` и нажмите Run.
3. Скопируйте `.env.example` в `.env.local` и заполните `SUPABASE_URL` и `SUPABASE_SERVICE_ROLE_KEY` (Project Settings → API).

Схема проверена на PostgreSQL 16: повторный запуск безопасен, неверные значения отклоняются ограничениями.
